# Gracias por llegar

Gracias por aparecer en mis dias con esa forma tuya de hacer que todo parezca un poco mas bonito.

Hay sonrisas que se olvidan rapido, pero la tuya se queda dando vueltas como una cancion favorita.

Por eso queria guardar unas palabras para ti aqui, en esta pequeña coleccion de cartas, para que cada una se sienta como un recuerdo abierto despacito.

No hace falta una fecha especial para escribirte algo lindo.

A veces basta con sentirte cerca, aunque sea en pensamiento, para que nazca otra carta.
